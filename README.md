# YOUR CHOICE — Phase 01 Public Storefront

Complete public-facing storefront UI/UX for **YOUR CHOICE®** (*Always The Best Choice · Independent by Design*), built with **React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion + React Router v7**.

## Highlights

- **Preserved Design Foundation:** Retains the exact reference homepage hero, typography (`Barlow Condensed`, `DM Sans`, `IBM Plex Mono`), palette (`#f5f5f1` paper, `#18191a` ink, `#2349ed` YC Royal Blue, `#57dbf3` cyan), scroll-driven Expression Orbit, 12-strip Editorial Shutter story, and horizontal Rail.
- **Official Brand Identity:** Integrates the official winged `YC` emblem, full logo lockup, stacked `YOUR CHOICE®` wordmark, and `YC®` monogram consistently across interior headers, auth split stages, About brand anatomy, Order Confirmation receipts, and the dark editorial footer.
- **24 Live Public Routes:** Homepage + all 23 Phase 01 storefront pages (Shop All, T-Shirt Collection, Polo Shirt Collection, Collection Details, Product Details, Search Results, Wishlist, Shopping Bag, Checkout, Order Confirmation, Order Tracking, Login, Registration, Forgot Password, Reset Password, About, Contact, FAQ, Size Guide, Shipping & Delivery, Returns & Refunds, Privacy Policy, Terms & Conditions).
- **Interactive Frontend State:** Persistent Shopping Bag (`YC10`, `INDEPENDENT`, `FREESHIP` promo codes + Rigid Collector Box option), Wishlist curation board, end-to-end Checkout → Order Confirmation → Live Order Tracking, Interactive Fit Finder (`CM` / `IN`), and Self-Service RMA Simulator.

See [`STOREFRONT_INVENTORY.md`](./STOREFRONT_INVENTORY.md) for the complete route matrix and implementation checklist.

npm install
